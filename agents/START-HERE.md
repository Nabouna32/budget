# START HERE

Avant toute intervention :

1. Lire `AGENTS.md`.
2. Lire `agents/AGENT-CONTRACT.md`.
3. Lire `agents/HANDOFF-CONTRACT.md`.
4. Lire le contrat spécialisé du rôle.
5. Lire les documents canoniques pertinents dans `docs/`.
6. Inspecter l'état Git réel, les branches, PR et Issues pertinentes.
7. Inspecter les checkpoints/handoffs pertinents.
8. Inspecter l'implémentation concernée.
9. Identifier les divergences entre documentation et code.
10. Présenter le périmètre et, si nécessaire, demander validation avant toute décision importante.

Ne jamais commencer par modifier le dépôt sur la seule base d'une conversation précédente.
