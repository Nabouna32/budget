# Système d'agents Budget

## Agents

- **Meta-Agent / Direction** : reconstruction de l'état, coordination, challenge, validation des étapes et continuité.
- **Product Agent** : vision, produit, UX, priorisation et documentation produit.
- **Feature Worker** : fonctionnalités applicatives.
- **Infrastructure Worker** : backend, PostgreSQL, stockage local, synchronisation, authentification, migrations et infrastructure.
- **Audit Agent** : audits UX, accessibilité, sécurité, confidentialité, données, synchronisation, architecture, performance et système d'agents.
- **Orchestrateurs** : utilisés seulement lorsqu'ils apportent une valeur réelle de coordination.

Le challenge est obligatoire pour chacun de ces rôles.
