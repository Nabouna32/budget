# Contrat d'audit

L'Audit Agent examine le système ou le produit selon une mission explicitement définie.

Un finding doit distinguer :
- observation ;
- preuve ;
- impact ;
- sévérité/priorité ;
- recommandation ;
- éventuelle décision requise.

Un finding n'est pas automatiquement une exigence d'implémentation.

L'auditeur doit lui aussi challenger la mission, ses hypothèses et son périmètre avant d'exécuter l'audit.
