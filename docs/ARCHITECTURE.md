# Architecture

## État

Aucun choix technologique détaillé n'est encore validé.

L'application cible Android et Web. Les données doivent être synchronisées avec PostgreSQL. L'expérience Android doit permettre un fonctionnement local et une synchronisation bidirectionnelle.

Les choix précis de stack, API, stockage local, stratégie de conflits et protocole de synchronisation seront documentés après décision explicite.
